# Image-to-PDF-Converter-Mobile-App
</div>
An Android app for converting images to PDF files and viewing PDFs. Image-to-PDF conversion, saved files, and PDF viewing work offline on the device. Cloud storage is optional.

## Install On Android

1. Open the [Releases](https://github.com/ClimberCoder/Image-to-PDF-Converter-Mobile-App/releases) page on your phone.
2. Open the newest release and download `app-release.apk`.
3. Open the APK and allow installation from that source if Android asks.

The app supports Android 7.0 (API 24) and newer. The APK is built automatically by GitHub Actions when a version tag is published.

## Build Locally

**Prerequisites:** [Android Studio](https://developer.android.com/studio) and Android SDK 36.

1. Open this repository in Android Studio.
2. Allow the project to sync.
3. Run the `app` configuration on an emulator or Android device.

AI features are optional. To enable them, create a local `.env` file and set `GEMINI_API_KEY` as shown in `.env.example`. No cloud account is required for offline image-to-PDF conversion or PDF viewing.
